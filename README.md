# 🚂 The Local Train — Interactive Music Archive & Fan Tribute

> *"A cinematic, atmospheric listening sanctuary dedicated to the timeless music and soul of **The Local Train**."*

---

## 🌟 About The Tribute

**The Local Train** is an iconic Hindi rock band that redefined independent music with their evocative songwriting, raw vocal energy, soaring guitar riffs, and deeply philosophical lyrics. From timeless anthems like *Choo Lo*, *Aaoge Tum Kabhi*, and *Khudi* to deep album tracks across *Aalas Ka Pedh* (2015) and *Vaaqif* (2018), their sound continues to resonate with millions of listeners.

This site is a **passion-driven digital archive and personal tribute** built for all fans of The Local Train. It provides a distraction-free, cinematic listening room where music meets smooth background visual art and responsive player controls.

---

## ✨ Features & Highlights

- 🎥 **Slow & Smooth Background Videos**: Seamless, slow-motion looped video backdrops hardware-accelerated for an immersive visual experience.
- 🎵 **Curated Discography**: Comprehensive listening experience featuring tracks from *Aalas Ka Pedh* (2015) and *Vaaqif* (2018).
- 💾 **Session State Persistence**: Automatically saves your last listened song, playback position, volume level, mute status, shuffle mode, and repeat mode in `localStorage` so you can pick up right where you left off.
- 🖥️ **Full Screen Cinema Mode**: Seamless full-screen mode with dedicated controls and keyboard shortcut.
- ⚡ **Minimalist & Responsive Design**: Crafted with elegant typography (*Fraunces* & *DM Sans*) and Tailwind CSS, optimized for mobile, tablet, and desktop viewports.
- ⌨️ **Keyboard Navigation**: Comprehensive hotkeys for effortless player control.

---

## ⌨️ Keyboard Shortcuts & Controls

| Shortcut | Action |
| --- | --- |
| `Space` | Play / Pause track |
| `←` / `→` | Previous track / Next track |
| `Shift` + `←` / `→` | Seek backward 5s / Seek forward 5s |
| `F` | Toggle Full Screen mode |
| `M` | Mute / Unmute audio |
| `A` | Open Album & Playlist browser |
| `Esc` | Exit Full Screen / Close menu overlays |

---

## 🛠️ Project Tech Stack

- **HTML5**: Native `<audio>` and dual-layer `<video>` hardware playback.
- **CSS3 & Tailwind CSS**: Utility-first styling, glassmorphism overlays, and smooth transitions.
- **Vanilla JavaScript (ES6+)**: Zero external JS dependencies. Light, fast state management and `localStorage` integration.

## 🚀 Quick Setup / Local Run

Since this is a lightweight static site, no node build steps or dependencies are required.

Run locally using any static web server:

```bash
# Clone the repository
git clone https://github.com/Suman-byte8/music-website.git

# Navigate to directory
cd music-website

# Start local server (Python 3 example)
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.
